# Changelog

## 0.2.0

- Theme library: import Obsidian themes / snippets / vault appearance settings through a folder picker into iMark's own global storage; select, remove and open the library from the command palette. Themes are no longer read from `.obsidian/themes` implicitly.
- Mermaid: all diagram types rendered in live preview and reading view (lazy-loaded, follows light/dark), click to open a zoomable preview modal.

## 0.1.0

- Initial release: live preview / source / reading modes, Obsidian syntax (wikilinks, embeds, tags, callouts, highlights, math, comments, frontmatter), Obsidian theme loading with hot reload, `[[` completion, image paste, Typora-style shortcuts.
